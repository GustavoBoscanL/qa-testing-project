# Resultados y Documentación de Mejoras

Esta carpeta contiene documentación opcional sobre bugs encontrados y recomendaciones de mejora durante las pruebas.

## Estructura Sugerida

- `bugs.md` - Lista de bugs encontrados durante las pruebas
- `improvements-ui.md` - Recomendaciones de mejora para la UI
- `improvements-api.md` - Recomendaciones de mejora para la API
- `quality-analysis.md` - Análisis general de calidad del sistema
- `ejercicio2-bug-report.md` - Bug report del Ejercicio 2

## Formato de Reporte de Bug

```markdown
### Bug #[N]: [Título del Bug]

**Severidad:** [Alta/Media/Baja]
**Prioridad:** [Alta/Media/Baja]
**Componente:** [UI/API]

**Descripción:**
[Descripción detallada del bug]

**Pasos para Reproducir:**
1. Paso 1
2. Paso 2
3. Paso 3

**Resultado Esperado:**
[Qué debería ocurrir]

**Resultado Actual:**
[Qué ocurre realmente]

**Evidencia:**
- Screenshot: [ruta]
- Video: [ruta]
- Logs: [ruta]

**Ambiente:**
- Navegador: [Chrome/Firefox/Edge]
- Versión: [versión]
- OS: [Windows/Mac/Linux]
```
